# UX: тултипы и подсказки в интерфейсе

Краткое руководство для контрибьюторов: единый паттерн подсказок в UI BirdLense Hub.

[English](./UX_TOOLTIPS.md)

## Принципы

- **Текст рядом с действием** — для критичного контекста, без которого оператор не завершит шаг.
- **Тултип** — для необязательных пояснений, побочных эффектов и ограничений.
- Не опирайтесь на нативный HTML-атрибут `title` как на основной носитель подсказки.

## Что где использовать

- **Подсказка в разметке (`Typography` / `Alert`)**
  - Предусловия и предупреждения (нужна авторизация, опасные действия).
  - Многошаговые инструкции для оператора.
- **Тултип (`<Tooltip />`)**
  - Кнопки только с иконкой и компактные действия.
  - Детали, которые не должны забивать макет.

## Правила реализации

- Отключённые кнопки оборачивайте в `<Tooltip><span><Button .../></span></Tooltip>`.
- Текст тултипа — короткий и привязанный к действию.
- Повторяющиеся формулировки выносите в i18n.
- Для опасных действий оставляйте диалог подтверждения, даже если есть тултип.

## Где уже применено

- **Библиотека:** единые тултипы для действий по обслуживанию датасета.
- **Неизвестные / проверка:** подсказки для кнопок применения и подтверждения.
