# UX: «На проверке» ↔ исправление вида в видео (#81)

[English](./UX_UNKNOWN_VIDEO_CORRECTION.md)

**Issue:** [#81](https://github.com/Gfermoto/BirdLense-Hub/issues/81)

## Проблема (взгляд оператора)

Ручная коррекция вида удобна, когда один выбор применяется к **многим** детекциям. Но режим проверки и коррекция **внутри видео** всё ещё могут ощущаться как **два разрозненных** сценария: правка строки в режиме проверки на таймлайне (`/timeline?review=1`, legacy `/unknowns`) и открытие той же детекции через **Открыть видео** с правкой на странице видео.

## Текущее поведение (технически)

- Оба пути вызывают один API: **`PATCH /api/ui/detections/:id`** с `species_id` (на сервере — связанная логика датасета/кропа).
- **Режим проверки на таймлайне** показывает строки с низкой уверенностью (данные `GET /api/ui/unknowns`); **Видео → Обнаруженные виды** группирует по виду/треку и позволяет объединять или исправлять.
- После коррекции или слияния из видео **`DetectedSpecies`** инвалидирует **`['unknowns']`** (и связанные запросы), чтобы страница «Неизвестные» перезапросилась — это нужно из‑за **5-минутного** `staleTime` React Query по умолчанию.

## Принципы UX (цель)

1. **Одна ментальная модель:** «Я исправляю **эту детекцию** (id `X`); список и страница видео — два входа».
2. **Видимая связь:** из режима проверки **Открыть видео** уже ведёт в контекст; опционально: тост или подсказка «Тот же API коррекции, что на странице видео».
3. **Без регрессий:** массовое слияние в видео и мультивыбор остаются как есть.

## План по фазам

| Фаза | Объём |
|------|--------|
| **A — Доки и микрокопи** | Справка на странице + i18n: явно, что «Неизвестные» и видео используют **один** API коррекции; поощрять «Открыть видео» для визуальной проверки. |
| **B — Навигация** | После исправления в режиме проверки: опционально «Остаться в списке» vs «Открыть видео» — **реализовано:** snackbar успеха содержит **Открыть видео** (по умолчанию остаётесь в списке; при наличии действия автоскрытие 10 с). |
| **C — Единая история** | **Реализовано:** правки пишут общие записи активности с `source` (`unknowns`/`video`), в режиме проверки показывается недавняя единая история коррекций. |
