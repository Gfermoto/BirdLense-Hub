# Тексты интерфейса: тон и вычитка (для оператора, не для разработчика)

[English](./UI_COPY_STYLE.md)

Чеклист для строк в веб-UI (локали `app/ui/locales/`).

## Аудитория

- Основной читатель: **владелец / оператор станции**, настраивающий хаб в браузере.
- Вторично: помощник с ограниченными правами.
- Не опираться на внутренние имена модулей, ключи YAML и фразы из логов — если только это не раздел **Сервис** / диагностика.

## Тон

- **Короткие подписи** в полях; в подсказке — *что изменится для пользователя*, а не устройство кода.
- Лучше **последствие** («Запись не начнётся»), чем внутренняя причина («ByteTrack вернул 0 треков»).
- В одной подсказке — одна мысль; не склеивать несколько оговорок подряд.

## Чего избегать в «Станция» (`/settings`)

- Сырые ключи конфига (`triggers.frigate.*`) в подписях полей — человекочитаемое имя; ключи оставить в документации или блоке YAML.
- Жаргон «expert / legacy / только Frigate», если элемент не вынесен в явный продвинутый или сервисный режим.
- Троекратное повторение одного и того же в подсказке, алерте и доке — выбрать **одно** основное место.

## Редактура

- Продуктовые тексты: проход **UX + шефредактор** для `en` / `ru` (и `zh`, если трогали).
- Техническая верность: сверка с `default_config.yaml` и OpenAPI, если поле влияет на поведение API.

## Инвентаризация настроек

Каждый терминальный ключ из `app/app_config/default_config.yaml` должен быть либо в `form.Field name="..."` под `app/ui/src/pages/Settings/`, либо в явном allowlist `scripts/check-settings-ui-coverage.py` (с категорией и обоснованием). Проверка:

```bash
python3 scripts/check-settings-ui-coverage.py
```
