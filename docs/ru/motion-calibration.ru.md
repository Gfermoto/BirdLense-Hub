# Калибровка MOG2 и фильтра статических объектов

Раздел **Настройки → Процессор → Калибровка движения и статики** (режим «Рабочее пространство»).

## Превью

Кнопка **Тест / превью** вызывает `GET /api/debug/motion-preview`:

| Режим | Что показывает |
|--------|----------------|
| MOG2 детекции | Маска foreground для `processor.background_subtraction_*` (отсечение боксов на фоне) |
| MOG2 триггера | Маска `triggers.opencv` MOG2 (старт записи по движению) |
| Статика + MOG2 | То же, что детекция, плюс подсказки по static-фильтру |

Превью берёт текущий кадр с go2rtc (первая настроенная камера или `camera_id` в query). В запрос можно передать `overrides` (JSON) — UI отправляет несохранённые значения формы.

## Параметры

### MOG2 детекции (`processor.*`)

- **history** — длина модели фона; больше — стабильнее, медленнее адаптация.
- **varThreshold** — чувствительность к изменению пикселя; ниже — больше «движения» (ветка, IR).
- **min foreground ratio** — доля foreground внутри bbox; выше — жёстче отсев статики (риск FN).
- **warmup** — кадры до включения фильтра.
- **detect shadows** — учёт теней MOG2 (часто даёт FP на кормушке).

Применяется **без рестарта** на следующем кадре сессии.

### Триггер OpenCV (`triggers.opencv`)

- **detection_method** — `frame_diff` (CPU), `mog2`, `hybrid`.
- **mog2_var_threshold**, **mog2_min_contour_area**, **mog2_detect_shadows**.

После сохранения настроек может потребоваться **перезапуск процессора** (детектор триггера создаётся при старте). Превью с `overrides` позволяет подобрать значения до сохранения.

### Статические объекты

- **static_object_suppression_enabled**
- **static_scene_bird_min_confidence** — порог, ниже которого «квадратная» статика отбрасывается.
- **static_temporal_max_jitter_px** — допустимый джиттер центра; меньше 2 px — риск FN для медленных птиц.

## Условия съёмки

| Условие | Рекомендация |
|---------|----------------|
| Ветка / листья | Поднять `min_contour_area`, `varThreshold`; включить smart trigger |
| Ночь / IR | Профиль night, ниже `diff_threshold`, осторожно с shadows |
| Статичная кормушка | MOG2 детекции + static filter; смотреть превью маски |
| Дальние птицы | Не завышать `min_contour_area` и `min_fg_ratio` |

## API

```http
GET /api/debug/motion-preview?mode=detection_mog2&camera_id=BirdBox
```

Требуется доступ к настройкам (пароль). Ответ: `image_jpeg_base64`, `mask_jpeg_base64`, `warnings[]`.
