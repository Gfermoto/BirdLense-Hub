# Слияние и распознавание: консилиум и мозговой штурм

Документ для обсуждения проблем слияния (YOLO + Frigate + BirdNET) и ошибочного распознавания.

---

## 1. Текущая архитектура

### Распознавание (YOLO)

- **Binary detector** — птица/не птица
- **Classifier** — вид (EU: birds-525 + iNaturalist, ~491 вид)
- **ByteTrack** — треки по кадрам
- **DecisionMaker** — фильтры:
  - `min_track_duration` (2 сек) — короткие треки отбрасываются
  - `min_confidence_to_process` (0.10) — порог voting × classifier
  - `species_confidence_overrides` — пониженные пороги для редких видов
- **Voting** — самый частый вид в треке, combined confidence = voting_ratio × avg_classifier_conf

### Слияние (species_normalizer.merge_detections)

- **YOLO** — треки по виду, объединяются по `dedup_window_seconds` (60 сек); мерж в детекцию с наименьшим разрывом (gap)
- **MQTT** — Frigate, BirdNET; окно `merge_window_seconds` (8 сек) вокруг timestamp; мерж в детекцию с наибольшим перекрытием
- **Bird filter** — если Bird + другой вид → убрать Bird, перенести frames в другой
- **one_per_species** — гарантированно один результат на вид (устраняет дубликаты к одному посещению)
- **source_priority** — при конфликте (разные виды, перекрытие ≥3 сек): оставляем вид с более высоким приоритетом (yolo > frigate > birdnet)

## 2. Проблемы слияния

### 2.1 Окна и тайминги

| Параметр | Значение | Статус |
|----------|----------|--------|
| `merge_window_seconds` | 8 | Увеличено с 5 для лучшего слияния MQTT |
| `dedup_window_seconds` | 60 | Увеличено с 45; детекции с разрывом >60 сек — разные визиты |
| `one_per_species` | true | Гарантированно один результат на вид |
| `source_priority` | ["yolo","frigate","birdnet"] | При конфликте видов — приоритет источника |

**Реализовано:**
- Мерж YOLO: выбор детекции с наименьшим gap (не первая попавшаяся)
- Мерж MQTT: выбор детекции с наибольшим перекрытием по времени
- Финальное объединение: один результат на вид (max confidence, объединённый интервал)
- Конфликт разных видов (перекрытие ≥3 сек): оставляем по source_priority

### 2.2 MQTT timestamp

- Frigate: `event.start_time` vs время реальной детекции — может отличаться
- BirdNET: время события vs время появления птицы на видео
- Если MQTT приходит «не вовремя», слияние с YOLO не срабатывает → дубликаты или потеря

**Идеи:**
- Расширить merge_window для BirdNET (голос может быть до/после появления птицы)
- Опция: игнорировать MQTT, если YOLO уже уверенно определил вид (или наоборот — доверять MQTT при конфликте)

### 2.3 Разные виды от разных источников

**Реализовано:**
- `source_priority`: ["yolo", "frigate", "birdnet"] — при конфликте (разные виды, перекрытие ≥3 сек) оставляем вид с более высоким приоритетом
- YOLO: Great Tit, BirdNET: Blue Tit (перекрытие) → остаётся Great Tit (yolo выше)

**Идеи на будущее:**
- Консилиум: если 2 из 3 источников согласны — брать их результат
- Confidence-weighted: брать вид с максимальным confidence среди всех источников

### 2.4 Bird vs конкретный вид

- YOLO: Bird (generic), Frigate: Great Tit → Bird убирается, остаётся Great Tit ✓
- Обратный случай: YOLO: Great Tit, Frigate: Bird — оба остаются, Great Tit с frames ✓
- Проблема: YOLO часто даёт Bird при низкой уверенности; Frigate может ошибаться в другую сторону

## 3. Проблемы распознавания (YOLO)

### 3.1 Похожие виды

- Синицы (Great Tit, Blue Tit, Coal Tit)
- Воробьи (House Sparrow, Tree Sparrow)
- Дрозды, зяблики и т.п.

**Идеи:**
- `species_confidence_overrides` — понизить порог для «сложных» видов
- Региональный фильтр — исключить невозможные в регионе виды
- Дообучение на своих кадрах (dataset export → train → best.pt)

### 3.2 Условия съёмки

- Низкое освещение
- Размытие (blur detection есть, но не всегда срабатывает)
- Частичная видимость (птица за кормушкой)
- Ракурс (вид сзади, снизу)

**Идеи:**
- Повысить `min_confidence_to_process` — меньше ложных, но больше пропусков
- Улучшить blur detection (порог, калибровка)
- Отбрасывать кадры с variance < X

### 3.3 Voting и confidence

- Один кадр с высокой уверенностью «перевешивает» много кадров с низкой
- Короткий трек (2–3 сек) — мало голосов, шум

**Идеи:**
- Медиана вместо среднего по confidence
- Минимальное число кадров для принятия решения
- Взвешенное голосование по confidence (не просто most_common)

### 3.4 Модель

- EU-модель: birds-525 + iNaturalist — не все локальные виды
- Подвиды, возраст (juvenile) — отдельные классы, путаница

**Идеи:**
- Проверить список классов модели vs типичные виды у кормушки
- Дообучение на своих данных
- Упрощение: объединять подвиды в один «родительский» вид
