# Каноническая UX-карта BirdLense

[English](./UX_CANONICAL_MAP.md)

Эта карта фиксирует основной маршрут для каждой роли и задачи после UX-reset.

## Роли

| Роль | Основные маршруты | Главная цель |
|------|-------------------|--------------|
| `guest` | `/`, `/timeline`, `/species`, `/migration-calendar`, `/species-directory`, `/species/:id`, `/live`, `/food` | Смотреть птиц, искать записи, открывать карточки видов. (`/species` и `/migration-calendar` — один и тот же экран сезонности.) |
| `contributor` | маршруты гостя + `/timeline?review=1` | Исправлять сомнительные распознавания и улучшать качество модели. |
| `admin` | маршруты contributor + `/settings`, `/system`, `/library` | Настраивать станцию, обслуживать данные и использовать сервисные инструменты. |

## Основные пользовательские сценарии

1. Первый запуск станции
   - `/settings`
   - Подключение камер и источников записи
   - Настройка уведомлений и интеграций
   - Настройка распознавания
   - `/system` для проверки здоровья станции

2. Найти и посмотреть запись
   - `/timeline`
   - Выбрать день с файлами
   - Открыть визит
   - `/videos/:id`

3. Найти вид птицы
   - `/species` (или `/migration-calendar` — тот же экран) для таблицы сезонности; `/species-directory` — карточный каталог
   - Найти вид
   - `/species/:id`
   - Вернуться в `/timeline?speciesId=<id>` за исходными записями

4. Исправить распознавание
   - `/timeline?review=1`
   - Открыть запись как доказательство
   - Подтвердить или исправить вид
   - `/system` → улучшение распознавания, когда накоплено достаточно исправлений

5. Сервис и обслуживание архива
   - `/system` для здоровья станции, диагностики и улучшения распознавания
   - `/library` для архива, выгрузок, хранилища, прогона и обслуживания

## Значение маршрутов

| Маршрут | Значение |
|---------|----------|
| `/timeline` | Повседневная работа с записями |
| `/timeline?review=1` | Очередь проверки сомнительных распознаваний |
| `/species` | Сетка сезонности (визиты × вид × месяц); в меню — **Виды** |
| `/migration-calendar` | Тот же компонент, что `/species` (алиас URL) |
| `/species-directory` | Каталог видов карточками |
| `/settings` | Настройка станции по результатам, а не по внутренним подсистемам |
| `/system` | Сервисный обзор и инструменты поддержки |
| `/library` | Архив данных и обслуживание |
