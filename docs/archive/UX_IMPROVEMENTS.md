# UX: недоработки и предложения по улучшению

## Исправлено

### 1. Неизвестные — дефолт по часу вместо дня
**Проблема:** При открытии страницы «Неизвестные» по умолчанию использовался текущий момент (например 12:00). Логика считала, что выбран час, и запрашивала только 12:00–12:59. Птица в 11:39 не отображалась.

**Исправление:** Начальное значение изменено на `dayjs().startOf('date')` — по умолчанию показывается весь день.

### 2. Неизвестные — лимит и предупреждение
**Исправление:** Лимит запроса увеличен до 500 (API поддерживает). При 500 записях показывается подсказка: «Показано до 500 записей. Выберите конкретный час для точного поиска.»

### 3. Timeline — дефолтная дата
**Исправление:** `selectedDate` по умолчанию `dayjs().startOf('date')` — единообразие с другими страницами.

## Рекомендуемые улучшения

### 4. Активность (System → Календарь) — только текущий месяц
**Проблема:** `StaticDatePicker` с `readOnly` всегда показывает текущий месяц. Нет возможности посмотреть активность за прошлые месяцы.

**Предложение:** Добавить выбор месяца (например, `MonthPicker` или кнопки «← месяц» / «месяц →») и передавать выбранный месяц в API.

### 5. Неизвестные — пустое состояние
**Текущее:** «Нет детекций с низкой уверенностью за выбранный период.»

**Улучшение:** Добавить подсказку: «Попробуйте другой день или час. Вид «Птица» (Bird) всегда показывается здесь для проверки.»

### 6. Неизвестные — выбор часа (низкий приоритет)
**Текущее:** DateTimePicker с `views={['year', 'month', 'day', 'hours']}`. При выборе 11:00 показывается час 11:00–11:59. Логика `hour() !== 0 || minute() !== 0` — при 00:00 считается «весь день».

**Потенциальная путаница:** Если пользователь выбирает 11:30 (минуты не 0), показывается час 11:00–11:59. Это ожидаемо. Но label «Выберите дату и время» может не подсказывать, что при выборе часа фильтруется только этот час.

**Предложение:** В подсказке/help уточнить: «При выборе времени (не 00:00) показываются только детекции за выбранный час.»

## Низкий приоритет

- **RecordingsAndDataset:** `operationsPeriod` по умолчанию «последняя неделя» — ок.
- **Overview:** `selectedDay = dayjs()` — всегда сегодня, логично.
- **Timeline:** Ограничение API «не более 1 дня» — при выборе «night» (22–06) диапазон корректен (через полночь).
