# Рефакторинг документации — консилиум и ревью

[English](./DOCS_REFACTOR_CONSILIUM.md)

Регламент **осмысленного рефакторинга** `docs/` и **обязательного ревью** после порции правок. Роли можно проходить **одному** по чеклисту (разные «шляпы»).

---

## Состав консилиума (роли)

| Роль | Фокус |
|------|--------|
| **Архивариус** | Структура `docs/`, дубли, [SITE_MAP](./SITE_MAP.ru.md), **nav** в `mkdocs.yml`, `archive/` |
| **Оператор** | [INSTALL](./INSTALL.ru.md), [SCENARIOS](./SCENARIOS.ru.md), [CONFIGURATION](./CONFIGURATION.ru.md) соответствуют реальному деплою |
| **Интегратор** | [API](./API.ru.md), OpenAPI, примеры, без секретов и «живых» хостов |
| **Читатель-новичок** | Путь **Run** из [README](./README.ru.md) без внутреннего жаргона |
| **I18n** | Пары EN/RU, [I18N_STATUS](./I18N_STATUS.md) |

---

## Фазы

1. **Инвентаризация** — что трогаем; расхождения с SITE_MAP и навигацией сайта.
2. **Принципы** — одна правда, меньше копипаста, плейсхолдеры, двуязычие там, где текст для людей.
3. **Исполнение** — небольшие PR (лучше одна зона за раз).
4. **Ревью** — чеклист ниже; зафиксировать результат (принято / доработать).

---

## Чеклист ревью (после каждой порции)

- [ ] `mkdocs build --strict` локально или в CI.
- [ ] Нет секретов, токенов, приватных IP ([SECURITY](./SECURITY.ru.md)).
- [ ] Внутренние ссылки в `docs/` рабочие; внешние — осознанно.
- [ ] Изменение поведения для пользователя → [CHANGELOG](./project/changelog.md).
- [ ] Если трогали версию/баннер → `VERSION` и `extra.site_version` в `mkdocs.yml` ([VERSIONING](./VERSIONING.ru.md)).
