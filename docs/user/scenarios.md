# Сценарии использования

## Типовая кормушка

1. IP-камера смотрит на кормушку
2. RTSP поток → BirdLense Hub
3. Детектор находит птицу → классификатор определяет вид
4. ReID проверяет, была ли эта особь раньше
5. Welfare оценивает состояние
6. Система записывает видео и отображает в Timeline

## Несколько кормушек

- Несколько RTSP потоков
- Каждая камера — отдельный источник в конфиге
- Timeline группирует по камерам

## Интеграция с Frigate

- Frigate отправляет события через MQTT
- BirdLense Hub подхватывает и обрабатывает
- Можно использовать Frigate как детектор движения

## Интеграция с BirdNET

- BirdNET определяет птиц по звуку
- Результаты через MQTT → BirdLense Hub
- Комбинируется с визуальной детекцией

## Гражданская наука

- Публичные записи
- Экспорт в eBird, iNaturalist
- PDF-отчёты для отчёта перед сообществом

## Автономный режим

- Без интернета: все функции работают локально
- MQTT брокер (встроенный Redis) не требует внешнего сервера
- Весь модельный стек — ONNX GPU, без облачных API
