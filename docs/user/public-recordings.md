# Публичные записи

## Структура директории

```
app/data/recordings/YYYY/MM/DD/HHMMSS/
├── video.mp4            # запись визита
├── metadata.json        # метаданные (вид, уверенность, трек)
└── crops/               # кропы птиц (опционально)
```

## Доступ через веб-интерфейс

Все записи доступны через вкладку Timeline. Экспорт:
- CSV — таблица визитов
- JSON — полные метаданные
- eBird — формат для eBird
- PDF — отчёт за период

## Поиск записей

Через веб-UI: Timeline → фильтр по дате, виду, камере.

Через файловую систему:

```bash
find app/data/recordings/ -name "video.mp4" | head -10
```

## Ручной импорт

System → «Сканировать и импортировать» — пересканирует директорию записей.

См. [`features.md`](features.md).
