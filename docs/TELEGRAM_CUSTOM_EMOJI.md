# Как получить ID кастомных эмодзи для Telegram

Кастомные эмодзи (Premium) используются на кнопках в сообщениях BirdLense. ID — строка вида `"1234567890123456789"`.

## Способ 1: @RawDataBot

1. Отправьте боту @RawDataBot сообщение с кастомным эмодзи (или перешлите сообщение, содержащее его).
2. В ответе найдите `custom_emoji_id` в entities.
3. Скопируйте значение (числовая строка).

## Способ 2: Через своего бота (getUpdates)

1. Отправьте своему боту сообщение с кастомным эмодзи.
2. Вызовите `https://api.telegram.org/bot<TOKEN>/getUpdates`.
3. В `message.entities` найдите объект с `type: "custom_emoji"` и полем `custom_emoji_id`.

## Примеры ID (публичные стикеры Telegram)

| Эмодзи | Пример ID | Источник |
|--------|-----------|----------|
| Птица | Зависит от стикера | @Stickers → поиск "bird" |
| Белка | Зависит от стикера | @Stickers → поиск "squirrel" |
| Live/ТВ | Зависит от стикера | @Stickers → поиск "live" |

ID уникальны для каждого стикера. Используйте @RawDataBot для точного значения.

## Настройка в BirdLense

Settings → Notifications → Custom emoji on buttons (включить) → ввести ID для птиц, белок, Open Live.
