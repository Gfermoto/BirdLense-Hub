# Карта UI (Записи → Станция → Сервис)

[English](./UI_SETTINGS_MAP.md)

Одна страница: **где в интерфейсе** живут пользовательские, contributor- и admin-сценарии. Где есть якоря — указаны hash-ссылки.

| Зона | Маршрут / вход | Для чего нужна |
|------|----------------|----------------|
| **Записи** | `/timeline` | Основной ежедневный сценарий: открыть ролик, посмотреть детекции, сделать экспорт. |
| **Проверка** | `/timeline?review=1` | Очередь contributor/admin для сомнительных распознаваний и ручных исправлений. |
| **Виды** | `/species` | Каталог видов, замеченных станцией. |
| **Сезонность видов** | `/migration-calendar` | Вторичный сезонный срез для изучения видов. |
| **Станция** (админ) | `/settings` | Настройка результата: камеры, уведомления, распознавание, интеграции. |
| **Сервис** (админ) | `/system` | Здоровье станции, улучшение распознавания, диагностика и сервисный режим. |
| **Данные** (админ) | `/library` | Проверка архива, выгрузка датасета, хранилище, прогон и обслуживание. |
| **Live** | `/live` | Потоки и оверлеи в рантайме, а не постоянная конфигурация. |
