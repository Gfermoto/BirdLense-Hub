# A/B классификаторов на избранных записях

**Дата:** 2026-05-27 · **Хост:** VPS prod (контейнер `birdlense`) · **Записей:** 14 избранных (`favorite=1`)

## Методика

- Кадры: 8 равномерно по длине ролика.
- Детектор: `best.pt` (крупнейший bbox; при промахе — центральный кроп).
- Классификаторы: **birder_eu** и **efficientnet_b2**, backend **OpenVINO**.
- Эталон «DB» — текущие метки Hub (`video_species` после полного пайплайна с трекингом).

Офлайн-кропы **не совпадают** с прод-пайплайном (треки, letterbox, отбор кадров) — сравнение с DB ожидаемо слабое; цель A/B — **поведение двух движков на одних кропах**.

## Сводка

| Метрика | Значение |
|--------|----------|
| Избранных обработано | 14 / 14 |
| EfficientNet: «абсурдные» глобальные виды | **14 / 14** |
| Birder (gated) совпал с DB top | 0 / 14 |
| Birder (raw argmax) совпал с DB top | 0 / 14 |
| Движки согласны друг с другом | 0 / 14 |

**EfficientNet** на каждом ролике даёт нерелевантную Европе/кормушке метку с высокой уверенностью (журавль, павлин, пеликан, тропическая птица, сова и т.д.).

**Birder** на тех же кропах чаще уходит в **Unknown** (класс «Unknown» в таксономии 707) — консервативно, без ложных экзотических видов.

## Вывод

1. **Вернуть EfficientNet на кормушку нельзя** — стабильные ложные глобальные виды на избранном.
2. **Birder на проде** (полный пайплайн) даёт осмысленные DB-метки; офлайн A/B их не воспроизводит из-за других кропов.
3. Для честного offline-совпадения с UI нужен прогон через `detection_strategy` / треки, не разреженный YOLO-sampling.
