# BirdLense Hub — short description (EN)

**RU:** [SHORT_DESCRIPTION.ru.md](./SHORT_DESCRIPTION.ru.md)

## Short

Local smart bird feeder monitoring: YOLO-based bird detection and species classification, optional BirdNET audio via MQTT, visit timeline, CSV/eBird export, and PWA web UI. Runs in Docker on x86, no cloud required.

## Extended

BirdLense Hub combines video and audio detection, keeps a structured species catalog, stores visit history, and provides operational tools for review, reporting, dataset export, and integrations (Go2RTC, Frigate, Telegram, webhook).
