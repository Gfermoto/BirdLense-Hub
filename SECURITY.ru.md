# Политика безопасности

## Поддерживаемые версии

| Версия | Поддержка          |
| ------ | ------------------- |
| 0.2.x  | :white_check_mark: |
| 0.1.x  | :white_check_mark: |
| < 0.1  | :x:                |

## Сообщение об уязвимости

При обнаружении уязвимости безопасности сообщите о ней ответственно:

1. **Не создавайте** публичный issue.
2. Создайте приватный [Security Advisory](https://github.com/Gfermoto/BirdLense-Hub/security/advisories/new) на GitHub, или
3. Свяжитесь с мейнтейнерами напрямую (см. описание репозитория).

Мы подтвердим получение и займёмся исправлением. Пожалуйста, дайте разумное время до публичного раскрытия.

## Рекомендации по безопасности

Для продакшен-развёртываний:

- Задайте `settings_password` в Настройки → Общие.
- Используйте `PROCESSOR_SECRET` и `FLASK_SECRET_KEY` (генерируются при `make setup` или деплое).
- Задайте `MCP_TOKEN` при включённом MCP.
- Храните секреты в переменных окружения, не в `user_config.yaml`.

Подробный анализ рисков: [docs/SECURITY.md](docs/SECURITY.md).
