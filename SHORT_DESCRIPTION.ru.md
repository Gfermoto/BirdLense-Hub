## Развёрнуто (подзаголовок, пресса)

**BirdLense Hub** — локальный мониторинг кормушки: компьютерное зрение (кастомный YOLO + трекинг) и опционально BirdNET по MQTT для детекции, определения вида, записи и разбора визитов — таймлайн, экспорт, уведомления и интеграции (Go2RTC, Frigate, Telegram, webhook). Работает в Docker на x86, без привязки к облаку.
