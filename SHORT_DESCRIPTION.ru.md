# BirdLense Hub — краткое описание (RU)

**EN:** [SHORT_DESCRIPTION.md](./SHORT_DESCRIPTION.md)

## Коротко

Локальная система мониторинга кормушки: детекция и распознавание видов птиц (YOLO), BirdNET по MQTT, таймлайн визитов, экспорт CSV/eBird, веб-интерфейс PWA. Запуск в Docker на x86, без облака.

## Расширенно

BirdLense Hub объединяет видео и аудио-детекцию, ведёт каталог видов, сохраняет визиты и даёт операционные инструменты: просмотр записей, отчёты, экспорт датасетов и интеграции (Go2RTC, Frigate, Telegram, webhook).
