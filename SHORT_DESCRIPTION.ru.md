# BirdLense Hub — краткое описание (RU)

**EN:** [SHORT_DESCRIPTION.md](./SHORT_DESCRIPTION.md)

## Коротко

Система мониторинга птиц на своей инфраструктуре: детекция и классификация видов (YOLO), BirdNET по MQTT, таймлайн визитов, экспорт CSV/eBird, PWA. Docker на x86; данные остаются у вас.

## Расширенно

BirdLense Hub сочетает видео и аудио, каталог видов и историю визитов для орнитологии и гражданской науки: проверка неуверенных детекций, экспорт в eBird и датасеты, интеграции с Go2RTC, Frigate, Telegram и webhook — без передачи ядра изображений в облако вендора.
