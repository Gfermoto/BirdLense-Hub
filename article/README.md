# Статья

Папка для подготовки научной статьи по BirdLense Hub.

## Структура

- `draft.md` / `draft.docx` — черновик статьи
- `figures/` — рисунки, скриншоты, диаграммы
- `supplementary/` — дополнительные материалы (датасеты, код)

## Связь с проектом

BirdLense Hub — исследовательский инструмент. См. [docs/DATASETS.md](../docs/DATASETS.md), [docs/TRAINING.md](../docs/TRAINING.md).
