# Статья

Папка для подготовки научной статьи по BirdLense Hub.

## Структура

- `draft.md` / `draft.docx` — черновик статьи
- `figures/` — рисунки, скриншоты, диаграммы
- `supplementary/` — дополнительные материалы (датасеты, код)

## Связь с проектом

BirdLense Hub — исследовательский инструмент. См. [docs/DATASET_TRAINING_PLAN.md](../docs/DATASET_TRAINING_PLAN.md), [docs/DATASET_SOURCES.md](../docs/DATASET_SOURCES.md).
