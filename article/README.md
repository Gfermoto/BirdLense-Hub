# Материалы для публикаций

## Хабр

- **Черновик статьи:** [habr.md](./habr.md) — заголовки, лид, полный текст с тегом `<cut />`, плейсхолдеры иллюстраций, теги.
- Перед выкладкой: обновить **версию** и список фич по корневому `README.md` / `CHANGELOG.md`.
- Картинки: см. `../screenshots/` или свои кадры; при публикации залить в хранилище Хабра и подставить URL.

## Научная / длинная статья (при необходимости)

- `draft.md` / `draft.docx` — развёрнутый черновик
- `figures/` — рисунки, скриншоты, диаграммы
- `supplementary/` — доп. материалы (код, таблицы)
