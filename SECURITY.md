# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

При обнаружении уязвимости создайте issue в репозитории или свяжитесь с maintainer.

Подробный анализ рисков: [docs/SECURITY.md](./docs/SECURITY.md)
