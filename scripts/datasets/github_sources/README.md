# Optional local dataset repos

Каталог для **локальных** `git clone` вспомогательных репозиториев. В git **не** коммитится (см. `.gitignore`).

Примеры (пути по желанию):

```bash
git clone https://github.com/UmairPirzada/BIRDS_SPECIES--IMAGE-CLASSIFICATION.git BIRDS_SPECIES--IMAGE-CLASSIFICATION
git clone https://github.com/SK124/Bird-Classification-Using-CNNs.git Bird-Classification-Using-CNNs
git clone https://github.com/pylabel-project/datasets_models.git datasets_models
git clone https://github.com/tonytw1/squirrel-detector.git squirrel-detector
```

Основной пайплайн датасетов — скрипты в `scripts/datasets/` и `datasets/new/`; см. [datasets (contributor)](../../../docs/contributor/datasets.md).
